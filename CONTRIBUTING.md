# Contributing

Thanks for interest in Floke Studio docs and landing.

## Scope

This repository hosts the studio landing page (`docs/`) and related scripts.

## Workflow

1. Branch from `main`
2. Keep changes focused (docs, copy, or site assets)
3. Open a pull request with a short summary

## Style

- Prefer clear, short copy
- Match existing Glyph/Floke naming and links
